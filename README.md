## 🚀 Run Locally

Clone the repository:

```bash
git clone https://github.com/zavil-huda/zavil-uiux-portfolio.git
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open:

```
http://localhost:3000
```
