# Design Philosophy

I believe great digital experiences are created by reducing friction, not by adding unnecessary complexity.

My design process focuses on understanding user behaviour, simplifying interactions, and creating interfaces that feel intuitive, accessible, and visually balanced.

Every project begins with solving a problem—not decorating a screen.

# Local Development

Clone the repository:

```bash
git clone https://github.com/zavil-huda/zavil-uiux-portfolio.git
```

Move into the project directory:

```bash
cd zavil-uiux-portfolio
```

Install project dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Visit:

```
http://localhost:3000
```

---

# Production Build

Create an optimized production build:

```bash
npm run build
```

Run the production server:

```bash
npm start
```

---

# Deployment

This portfolio is deployed using **Vercel** with automatic deployments connected to GitHub.

Every commit pushed to the `main` branch automatically generates a new production deployment, making future updates simple and efficient.
